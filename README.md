# Faedpyme
This repository belongs to Grupo Red at the Tecnológico de Antioquia and contains the source code and related files for the development of a form designed to collect information on Talent Management in Ibero-America . This project is driven by Faedpyme , the Foundation for Strategic Analysis and Development of Small and Medium Enterprises, with the aim of gathering key data to analyze and improve talent management practices in the region 5.

The repository includes all versions of the form, technical documentation, and necessary resources for its implementation. Additionally, a README file is provided with details about the project's purpose, usage instructions, and collaboration guidelines 7. This space is intended to facilitate collaboration between members of Grupo Red and other researchers or developers interested in contributing to the advancement of this study 9.

Keywords: Talent Management, Ibero-America, Faedpyme, Grupo Red, Tecnológico de Antioquia, Form, Open Source.
